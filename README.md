## 🛡️ About Me

I am a cybersecurity engineer and full-stack developer from **Parul University** specializing in **Threat Detection Engineering**, **Security Operations (SOC)**, and **Full-Stack Security Tooling**. 

My work bridges the gap between offensive adversary modeling (**MITRE ATT&CK®**) and defensive automation — engineering platforms that ingest raw multi-source telemetry, detect suspicious behaviors via sliding-window correlation, and streamline forensic triage for security analysts.

- 🔍 **Primary Focus**: Explainable detection logic, SIEM log telemetry normalization, and automated security incident response.
- 🛠️ **Engineering Philosophy**: Defense through explainability — every alert must trace back to explicit, deterministic forensic evidence.
- 🎯 **Career Goal**: Security Operations Center (SOC) Analyst / Detection Engineer / Application Security Engineer.
